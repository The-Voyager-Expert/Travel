Fix: Single row with horizontal scroll. Content appears immediately below, not pushed down by filter rows. Swipe to see more filters. Same pattern as GetYourGuide, Viator, Klook mobile.
CSS change: On mobile, override #region-filters with overflow-x: auto; -webkit-overflow-scrolling: touch; flex-wrap: nowrap; padding-bottom: 4px; and set child chips to white-space: nowrap; flex-shrink: 0. No layout changes to the cards below.
