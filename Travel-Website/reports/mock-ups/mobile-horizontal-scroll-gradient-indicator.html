Mockup — Add right-edge gradient fade to .best-of-region-filters horizontal scroll strip

2026-08-13 · mobile.css · @media (max-width:600px) and (pointer:coarse) · Finding: mobile-horizontal-scroll-gradient-indicator
Change: add position:relative; overflow:hidden to the parent wrapper and ::after { position:absolute; right:0; top:0; bottom:0; width:40px; background:linear-gradient(to right,transparent,var(--bg)); pointer-events:none; } on the wrapper. Scrollbar is already hidden via scrollbar-width:none — without this gradient the strip gives no visual affordance that more chips exist beyond the right edge.
BEFORE — hidden scrollbar, no affordance cue
Best-Of page content. The filter chips above can be scrolled sideways — but there is NO visual cue that more chips exist to the right. The scrollbar is hidden. Users don't know "Middle East" and further chips exist.
⚠ No gradient. No scrollbar. Invisible scrollability — users may not discover all filter options.
AFTER — gradient fade signals more content to the right
The gradient fade on the right edge tells users there are more chips to scroll to. Benchmark: Klook, Booking.com, GetYourGuide all use this gradient-fade pattern universally on horizontal pill strips.
✓ 40px gradient fade using var(--bg) (#f5f3ef). Pointer-events:none so chips beneath are still tappable. Only the wrapper div needs position:relative; overflow:hidden.
