Add prefers-reduced-motion media query

Finding logged 2026-08-08 · Target: append to web-travel-style.css · Effort: S · WCAG 2.3.3 (AAA)

BEFORE Transitions fire for all users

Kyoto

Users with vestibular disorders who set "Reduce Motion" in their OS still see the card lift, image zoom, and all CSS transitions. Zero prefers-reduced-motion rules exist in the site CSS.

AFTER Transitions suppressed for reduced-motion users

Kyoto

This panel simulates what reduced-motion users see: hover state is immediate (no animation), image does not zoom. Content remains fully accessible.

The fix is a single media query. For normal users, nothing changes — all transitions still fire.

Fix — append at bottom of web-travel-style.css

@media (prefers-reduced-motion: reduce) { *, *::before, *::after { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; } }
