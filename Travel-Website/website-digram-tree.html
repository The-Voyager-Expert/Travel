Mobile

(max-width: 1260px) and (pointer: coarse)

The top strip is replaced by the hamburger, which carries two tiers: the same nine tabs, then a terracotta band, then the nine category groups that reach all 56 essentials/ pages. That second tier exists because the home page's Trip Resources block — the desktop route to those pages — is hidden at this width. The Best Of list is swapped for a cover tile, and five phone-only tiles sit under it.

The nine groups hold the same 56 pages as the Trip Resources block in the desktop diagram — see that block for the full list. Two differences, both deliberate: Car Rental is one row here, not eight (its seven continent rows on the landing block are anchors into one page, and a second disclosure level in a phone menu buys no new page), and the group holding the page you are on opens itself with that row marked. This list is hand-maintained in assets/toolbar.js, not in ITEMS — nine groups in ITEMS would put nine dropdowns on the desktop top strip, which has no space for one.

Four of the five tiles are showcase carousels (packing, When to Go, Before You Go, the map) walking 3–4 screens behind a pair of arrows; the plug tile is deliberately one screen, because there is no sequence to walk there. Every screenshot is regenerated from the live page, never hand-edited; the recipe sits in the comment above each tile in index.html.

What differs — read this before "fixing" either side
SurfaceDesktopMobile
The nav Nine pills on the top strip. No dropdown. Hamburger. Same nine tabs, plus a second tier of nine categories.
The 56 essentials pages Home page, Trip Resources block — nine closed disclosures. Hamburger tier 2. The block itself is hidden here.
Best Of 34 bare-name rows on the home page, each going straight to its category. One cover tile opening /best-of/ first, then the category.
Plug · Packing · Map · When to Go · Before You Go Reached from the toolbar and Trip Resources. No tiles. Five picture tiles under Best Of, four of them carousels.
Car Rental One row that opens seven continent sub-rows. One row. No sub-tier.

The two sides are not supposed to match, in either direction. A phone goes home page → /best-of/ → category; desktop goes home page → category and never visits /best-of/. Both directions have shipped wrong once already — a summary line added to all 34 desktop rows, and the desktop flow nearly rerouted through /best-of/ "to make them match". Making them match is a redesign of whichever side moves, and that is an owner decision.
