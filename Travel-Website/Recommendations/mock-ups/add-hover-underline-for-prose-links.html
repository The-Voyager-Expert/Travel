CSS: The fix is scoped — add .prose a:hover { text-decoration: underline; } (or whichever class wraps body text). Pills, buttons, nav-chips, and cards already have text-decoration: none locked via their own class selectors, so they're unaffected. The global a:hover { text-decoration: none } at line 298 would need to move after the prose rule, or the prose rule needs higher specificity.
