OPEN Mobile filter chip strip: replace wrap with horizontal scroll ›

On mobile, the `#region-filters` chip strip uses `gap: 0` with wrapping children, causing filter chips to flow into multiple rows and push page content down. Replace with `overflow-x: auto; -webkit-overflow-scrolling: touch; flex-wrap: nowrap; white-space: nowrap;` to create a single-row horizontally scrollable strip. This is the dominant pattern on mobile at GetYourGuide, Viator, TripAdvisor, Booking.com, and Klook — it keeps filters accessible without consuming vertical space.

OPEN Add reading-column max-width to Trip-Essentials long-form text blocks ›

`.wrap { max-width: none; }` means paragraph text on Trip-Essentials pages spans the full container width — potentially very wide on large screens. Add `max-width: 720px` (and `margin: 0 auto`) to a `.prose` or `.reading-col` class applied to long-form text sections. This is a typographic best-practice: optimal line length is 60–80 characters, roughly 600–760px at 15px. The change should be scoped to text-heavy sections, not tables, card grids, or full-width filters.
